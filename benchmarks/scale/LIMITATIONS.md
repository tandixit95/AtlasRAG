# Limitations

- The current smoke artifact covers deterministic generation and integrity, not
  retrieval serving.
- It does not establish distributed coordination, persistence, ANN scale, update
  consistency, production traffic, customer use, or a service-level objective.
- Synthetic authorization metadata is regression evidence, not a security audit or
  proof of non-interference.
- The target 100M configuration has not been executed.
- Diagnostic elapsed time is host-dependent and is not an allowed performance claim.
- No raw large corpus should be committed; later measured runs require external,
  checksummed artifact storage and a complete environment manifest.
