# AtlasRAG v0.2.0

AtlasRAG v0.2.0 is the first public, evidence-backed release of the reconstruction-first retrieval core.

## Highlights

- Permission-aware BM25, exact dense retrieval, and RRF hybrid fusion.
- Deterministic source identity, content versioning, chunk provenance, and stable tie-breaking.
- Fail-closed tenant/group policies applied before corpus statistics, scoring, and fusion.
- 63 source tests plus clean wheel and source-distribution install/import gates.
- Reproducible SciFact and deterministic ArguAna-200 evidence with A/B ranking equality checks.
- Synthetic authorization and provenance smoke tests with zero unauthorized returns across nine checks.

## Scope boundary

This release does not claim production traffic, distributed serving, formal security certification, external adoption, peer review, or a production SLO. HNSW measurements in the evidence archive are neutral-harness results and are not an AtlasRAG package capability.

## Install

From the tagged source:

```bash
python -m pip install "atlasrag @ git+https://github.com/tandixit95/AtlasRAG.git@v0.2.0"
```

The release also provides wheel and source-distribution assets with a separate SHA-256 manifest.
